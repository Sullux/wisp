# Standard Library

This document outlines the core functions, data structures, and utilities that make up the Wisp standard library. These are available in the global scope of any Wisp program.

*(Note: The Wisp standard library is currently under design and development. The contents of this document are provisional and subject to change.)*

## Core Functions

This section will detail the essential built-in functions for control flow, logic, and basic operations.

*   **`log`**: Prints its arguments to the console.
*   **`=`**: Performs a strict equality check (JavaScript `===`).
*   **`if`**: Conditional branching.
*   ...and more.

## Data Structures

This section will cover functions for creating and manipulating core data structures.

*   **`Array`**: Creates a new array.
*   **`Object`**: Creates a new object.
*   **`map`**: Transforms a collection.
*   **`filter`**: Filters a collection.
*   **`reduce`**: Reduces a collection to a single value.
*   ...and more.

## Utilities

This section will include various helper functions for common tasks.

*   String manipulation functions.
*   Math functions.
*   Type checking functions.
*   ...and more.
