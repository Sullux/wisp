# Wisp

Wisp (Web Lisp) is a Lisp-like programming language that compiles to clean, readable, and efficient JavaScript. It is designed to provide the expressiveness of a Lisp while integrating seamlessly with the entire JavaScript ecosystem.

This repository contains the core Wisp compiler, language server, syntax highlighter, and documentation.

## Getting Started

To get a feel for the language and see a "Hello, World!" example, check out the **[Quick Start Guide](./INTRODUCTION.md#quick-start-hello-world)**.

## Contributing

This project is in its early stages, and contributions are welcome! If you're interested in helping, please feel free to open an issue to discuss potential changes or submit a pull request.

Key areas for contribution include:
*   **Compiler:** Improving the core transpilation logic and error handling.
*   **Language Server:** Enhancing IDE support and developer experience.
*   **Syntax Highlighter:** Adding support for more platforms and edge cases.
*   **Documentation:** Clarifying concepts, adding examples, and fixing errors.
*   **Standard Library:** Expanding the set of core functions available to all Wisp programs.
